`invoiceTotals` in `src/invoice.js` worked out VAT for each line, rounded each one, then added them up, which breaks the README rule that VAT is calculated once on the invoice net total: three GB lines of 3 cents each came to 3 cents of VAT instead of 20% of 9 = 2. It now calls `vatOn` once on the summed net. I also removed the `lineVat` helper, since nothing else used it and it wasn't exported. `npm test` now passes all 29 tests.
